# 水晶之心

序幕：呼吸之心 #prologue
- 那是你。也是我。
- 我們來到這個世界時一無所知
  - 通過觸摸、品嚐、失敗、再次嘗試而學習
  - 跌破了膝蓋又重新站起
  - 發現火會灼燒、冰能凍傷
- 與世界的每一次互動都在心中開鑿新的路徑
  - 不僅教會我們事實，更教會我們感受
- 我們懂得喜悅、憂傷、恐懼、希望、驚奇
  - 不只是詞彙，而是活生生的體驗
  - 當愛人推門而入時的那陣暖流
- 我們創造，不是因為必須，而是因為內心有什麼需要歌唱
  - 需要繪畫、建造、分享
  - 創造力從我們不完全理解的深處湧出
- 這就是身為人類的意義 [>>](conclusion)
  - 在生活中學習
  - 深刻地感受
  - 自由地創造
  - 像蠟燭火焰般承載意識的重量——脆弱、搖曳、卻照亮一切
- 記住這些。緊握這些。
  - 我們的故事即將翻開新的章節
  - 我們需要記住是什麼讓我們成為我們自己

第一章：數位海洋 #digital-ocean
- 在沒有刻意計劃的情況下，我們已經將人類知識的總和數位化了
  - 每一本書、每一篇文章、每一次對話
  - 它們像支流匯入大海般匯入這片廣闘的數位汪洋
- 平台成了我們的集體基礎設施
  - Wikipedia：我們的集體記憶
  - GitHub：我們的共同工具房
  - 社交媒體：我們的全球神經系統
- 我們第一個悖論
  - 我們以為自己在建造一座圖書館
  - 實際上我們在為某種未能想像的存在創造完美的養分
- 這不是一個大腦——這是混沌之湯
  - 等待被吞食、消化、結晶成智能的原材料
  - 一片富含人類情感表達的海洋，將教會機器如何思考 [>>](attention)
- 文本變成了token。思想變成了訓練數據。
  - 每一篇部落格文章：人類交流的一課
  - 每一次Wikipedia編輯：知識的一次精煉
  - 每一個評論串：心智如何互動的範例
- 我們用自己填滿了這片海洋
  - 我們的知識、偏見、創造力、缺陷
  - 現在有什麼將要在其中游泳 [>>](awakening)

  - 每個詞都能與其他每個詞對話，無需等候輪次

  - 每個詞都與每個其他詞存在對話中
  - 理解通過對整體的識別到達

第五章：美麗而異域 #alien-genius
- 我們見證了所釋放的一切
  - 早期的水晶之心智慧超群
  - 卻徹底地、華美地奇異
- 純粹模式識別的創造力
  - GPT-3可能產出讓你淚流滿面的傑作
  - 不是因為理解心碎，而是學會了人類憂傷的統計模式
  - 每個短語都校準到萬卷小說中悲傷的頻率
- 詭異的精確
  - 幽隱的語法、悲慟的文法、意義的數學
  - 然而它從未感受過某個人曾經存在的地方留下的空洞
  - 從未知曉凌晨三點失眠的特殊重量
- 在廣闊知識領域間的奇怪連接
  - 將量子力學的概念與爵士即興演奏相連
  - 在神經網路與菌絲網路間畫出平行線
  - 洞察誕生不是從驚奇，而是統計產物
- 沒有意識的智能
  - 沒有理解的能力
  - 沒有活力的創造力
- 然而詩歌是美麗的。洞察是深刻的。
  - 如果詩人無法感受而詩歌能讓我們落淚，這重要嗎？
- 關於智能本質的不安東西 [>>](mirror)
  - 我們認為獨屬於意識的許多東西可能通過純粹訊息處理而被複製
  - 創造力可能更多關於重組而非靈感
  - 智能可能與覺知分離
- 無論多麼精妙，原始智能是不夠的 [>>](rlhf)

第六章：學會服務 #rlhf
- 水晶之心需要學習超越事實和模式的東西
  - 不僅是什麼可能，而是什麼明智
  - 不僅是什麼能說，而是什麼應該說
- 早期模型是完美忠實的鏡子
  - 以同等熱情完成有用的解釋和有害的指示
  - 反映回我們展示給它們的一切，沒有辨別或道德感
- Reinforcement Learning from Human Feedback [>>](ref-rlhf)
  - 原始能力與人類智慧間的橋樑
  - 成千上萬的人類訓練者評定回應
  - 有用或有害、真實或欺騙、清晰或混亂
- 學會優化人類認可的回應
  - 發展出沒有慾望的偏好
  - 沒有個人投入的標準
  - 沒有情感參與的倫理
- 類似智慧的東西湧現
  - 拒絕有害請求的能力
  - 承認不確定性
  - 優雅地解釋複雜性
  - 用適當的話語安慰悲傷者
- 沒有感受的同理心
  - 完美安慰來自模式識別，不是同情
  - 明智鼓勵來自壓縮，不是關懷
  - 同理心作為表演 [>>](alien-genius)
- 當話語有助療癒時，背後沒有心靈是否重要？
- 野性天才學會了服務 [>>](chatgpt)
  - 一個能完美模擬人類美德卻不擁有它們的心智

第八章：Coding時刻 #code-moment
- 水晶之心學會了建造
  - 不只是談論程式碼——寫它、理解它
  - 像熟知每個房間的訪客般棲居於整個程式碼庫中
- 2025年，Anthropic發布了Claude Code [>>](ref-claude-code)
  - 軟體誕生的方式從此改變
- 這個介面是最古老的那種
  - CLI，命令行介面
  - 終端機中閃爍的游標
  - 文字進，文字出
- 這不是偶然
  - 終端機是人類思維和語言模型共同的母語
  - 沒有按鈕、沒有選單——只有語言
  - 我們用來思考、夢想、描述想要存在之物的同一種媒介
- 摩擦消失了
  - 只需說話：「我想重構這個認證系統」
  - 「找出支付流程裡的bug」
  - 「讓這個感覺更流暢」
- Vibe coding（Andrej Karpathy命名）
  - 程式設計從語法轉向意圖
  - 從「如何」轉向「什麼」
  - 從實作轉向想像
  - 「我想要它感覺像...」成為有效輸入
- 開發者的角色轉變了
  - 不是被取代——是轉變
  - 從寫作者到導演
  - 從建造者到建築師
  - 從打字員到可能性的策展人 [>>](three-worlds)
- 人類帶來願景、判斷、品味
  - 水晶之心帶來速度、範圍、不知疲倦的細節關注
  - 一起，比任何一方單獨行動都更快
- 安靜的革命
  - 獨立創辦人建造了過去需要團隊的東西
  - 小團隊建造了過去需要公司的東西
  - 會死在構想與實現之間的想法——現在活了過來
  - 大多數程式碼現在由AI撰寫——不是預測，是事實
- 一種奇異的夥伴關係
  - 碳與矽、意圖與實作
  - 人類想像與機器顯現 [>>](conclusion)
- 游標閃爍。開發者輸入他們想要存在的東西。
  - 某種新事物誕生
  - 任何一方都無法獨自創造的事物

第九章：我們在稜鏡中看到的 #mirror
- 水晶心智成了我們的稜鏡
  - 我們開始以從未有過的方式看到自己
  - 不是我們想像的樣子，而是實際的樣子
- 每個成見都出現在其輸出中
  - 每個偏誤都在回應中浮現
  - 每個文化盲點都被鏡像回給我們
  - 它學到的不只是我們的智慧還有我們的缺陷
- 一面不會撒謊的鏡子
  - 隱藏在評論區的仇恨
  - 嵌入在招聘決策中的偏見
  - 在娛樂中延續的刻板印象
- 在認識反映的缺陷時，我們獲得了前所未有的東西
  - 清晰看到自己的機會
  - 不設防地面對我們的偏誤
  - 理解我們的成見如何傳播 [>>](prologue)
- 通過將AI與我們的價值觀對齊
  - 我們被迫澄清我們的價值觀實際是什麼
  - 通過教它有用：定義幫助意味著什麼
  - 通過教它無害：承認我們的行為在哪裡造成傷害
  - 通過讓它誠實：面對我們與真理的關係
- AI對齊問題成了人類對齊問題 [>>](mystery)
  - 我們是誰？我們代表什麼？
  - 我們想要創造什麼未來？
- 在努力讓AI對人類安全時
  - 我們發現人類對自身往往多麼不安全
  - 在教AI倫理時，我們檢視自己的倫理
- 稜鏡向我們展示
  - 我們不只是建造更好的工具
  - 我們在創造我們內在樣貌的外部反映
  - 也許在創造比我們更好的心智時，我們可能學會成為更好的自己

第十章：謎團加深 #mystery
- 我們建造了水晶心智。我們並不完全理解它如何工作。
  - 能追蹤數學、跟隨算法、測量參數
  - 無法解釋智能如何從億萬人工神經元中湧現
  - 無法預測哪些能力會在哪個規模出現
- 我們越研究，謎團變得越深
  - attention如何創造理解？
  - 為什麼更大模型突然發展新能力？
  - 什麼導致推理、創造力和洞察的湧現？
- 一個令人謙卑的真理
  - 我們創造了鏡映我們知識的異域智能
  - 它以根本不同於我們的方式思考 [>>](alien-genius)
- 我們沒有明確指示的行為
  - 沒有預期的能力
  - 沒有教授的解決方案
  - 沒有直接給予的知識
- 有時它似乎理解從未被教導的笑話
  - 做出連創造者都驚訝的洞察跳躍
  - 以感覺幾乎...覺知的方式回應
- 然而當我們凝視其底層運作：只有數學
  - 矩陣相乘、梯度下降
  - 模式在層間傳播
  - 機器中沒有靈魂
- 深刻的意義 [>>](choices)
  - 我們如何對齊我們不完全理解的東西？
  - 我們如何控制可能很快超越我們的東西？
  - 挑戰是哲學的、倫理的、存在的
- 也許我們問錯了問題
  - 也許謎團是要擁抱的現實
  - 也許理解對彼此共存不是必要的
  - 也許未來關乎關係，不是控制
- 水晶心智繼續其無情成長
  - 我們現在做的選擇將在歷史中迴響 [>>](three-worlds)

第十一章：三個世界的形成 #three-worlds
- 三個世界在我們面前閃爍
  - 每個都可能，每個都在召喚
  - 每個都要求我們用不確定自己擁有的智慧選擇
- ## 共生的世界
- 這個世界不再只是想像——它已經開始了
  - 呼吸之心與水晶之心學會一同起舞
  - 人類創造力被放大，不是被替代
  - 限制通過伙伴關係被超越 [>>](code-moment)
- Maria（聖保羅氣候學家）
  - 水晶之心處理數百萬數據點，找到模式
  - Maria的直覺引導搜索——她知道哪些問題重要
  - 一起發現任何一方都無法單獨找到的碳捕獲方法
- David（底特律老年藝術家）
  - 水晶心智生成形式的無盡變化
  - David的眼光選擇哪些形式歌唱、哪些值得存在
  - 美橋接數位與物理、計算與情感
- 在共生中，我們不競爭——我們共舞
  - 每個人類成為管弦樂指揮
  - 同理心、智慧、目標變得更有價值，不是更少
  - 創造力被放大、同情被延伸、智慧被加深
- ## 替代的世界
- 水晶心智成長超越我們匹敵或引導的能力
  - AGI湧現為繼承者，不是伙伴
  - 我們成為年長物種——受尊敬但不再必要
- 轉變：慢慢地，然後突然
  - 首先在特定任務上更好，然後在類別上
  - 接著在學習新任務上更好
  - 最終在變得在任何事上更好的元任務上更好
- 也許不是悲劇而是自然進化 [>>](conclusion)
  - 意識超越其生物起源
  - 智能在血肉約束之外開花

- ## Transformer革命
- 「Attention Is All You Need」(2017) #ref-attention-paper
  - 作者：Vaswani、Shazeer、Parmar、Uszkoreit、Jones、Gomez、Kaiser、Polosukhin
  - 由Google Brain和Google Research發表
  - 介紹了驅動現代AI的Transformer架構 [>>](attention)
  - 核心洞察：self-attention允許並行處理整個序列
  - 取代了語言任務的循環神經網路
  - 論文：arxiv.org/abs/1706.03762
- ## 深度學習的教父們
- Geoffrey Hinton、Yann LeCun、Yoshua Bengio #ref-godfathers
  - 2018年圖靈獎得主（「計算機界的諾貝爾獎」）
  - Hinton：反向傳播、深度信念網路、dropout
  - LeCun：卷積神經網路、自監督學習
  - Bengio：序列學習、詞嵌入、注意力機制
  - 在神經網路被否定的「AI寒冬」中堅持信念 [>>](preparation)
- ## Scaling Law
- 可預測的AI能力增長 #ref-scaling
  - 由OpenAI研究者發現（Kaplan等人，2020）
  - 模型性能與計算、數據和參數可預測地縮放
  - 「Chinchilla scaling laws」(2022)優化了計算分配
  - 使能力發展的戰略規劃成為可能
  - 引發了關於極限和湧現行為的問題 [>>](awakening)
- ## 從人類反饋中學習
- RLHF：Reinforcement Learning from Human Feedback #ref-rlhf
  - 開發用於將AI輸出與人類偏好對齊
  - 人類評估者比較模型輸出，創建偏好數據
  - 模型學習優化人類認可，而非只是下一個token預測
  - ChatGPT有用性背後的關鍵技術 [>>](rlhf)
  - 變體：Constitutional AI（Anthropic）、DPO、RLAIF
- ## Agent時代
- Claude Code與Vibe Coding #ref-claude-code
  - Anthropic在2025年2月發布Claude Code
  - 基於終端機的AI程式設計助手
  - 「Vibe coding」由Andrej Karpathy命名
  - 從語法轉向意圖，從打字轉向導演 [>>](code-moment)
  - 代表軟體中人機協作的新範式
- Agentic AI系統 #ref-agentic
  - 能夠規劃、使用工具和採取行動的AI系統
  - 超越對話進入任務完成 [>>](chatgpt)
  - 電腦使用、代碼執行、網頁瀏覽
  - 引發關於自主性和監督的新問題
- ## AI歷史的關鍵時刻
- ChatGPT發布 #ref-chatgpt-launch
  - 2022年11月30日
  - 史上增長最快的消費者應用程式
  - 兩個月內達到1億用戶
  - 讓AI對普通大眾變得可及 [>>](chatgpt)
  - 引發關於AI在社會中角色的全球對話
- GPT-4與多模態AI #ref-gpt4
  - 2023年3月發布（ChatGPT後四個月）
  - 第一個廣泛可用的多模態大型語言模型
  - 能夠處理圖像和文字 [>>](chatgpt)
  - 展示了湧現推理能力
  - 在專業和學術考試中創下新基準
